VOLTEN — YOUR OWN WEBSITE SOURCE

This is a plain HTML, CSS, and JavaScript website. It does not use Shopify, Wix, Squarespace, React, or another website builder.

FILES
- index.html: page content and structure
- style.css: colors, layout, typography, and responsive design
- script.js: product filters and preview dialog

RUN IT ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the VOLTEN_source folder in Visual Studio Code.
3. Double-click index.html (or right-click and choose Open with your browser).
4. Edit the files and refresh the browser to see changes.

IMPORTANT
This is a front-end website preview. It is not connected to a real product database, email signup, payment processor, checkout, or order system. The product cards are marked as concepts / coming soon. Do not accept orders until you have confirmed product designs, fitment, supplier rights, pricing, shipping, and a secure payment setup.

The Google Fonts import is optional; if you want the site to work without external font loading, remove the @import line at the top of style.css.
