VOLTEN — WEBSITE SOURCE WITH PRE-LAUNCH CART

WHAT WORKS
- Add concept products to the cart
- Open and close the cart drawer
- Increase/decrease quantities and remove items
- Cart item count updates

NOT LIVE YET
Products are still concepts and prices are not confirmed. Checkout is intentionally disabled. This preview does not collect payments, shipping details, or orders.

TO ACTIVATE REAL CHECKOUT
A parent/guardian should help set up and manage the ecommerce and payment accounts. Once products, prices, stock, and fitment are confirmed, create the products in Shopify and connect the Shopify store domain and product variant IDs to this site. Never put payment secret keys in these public website files.

PUBLISHING
Upload index.html, style.css, and script.js to the ROOT of the GitHub repository, replacing the old files, then commit changes. Wait for GitHub Pages to redeploy.
